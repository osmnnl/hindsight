Hindsight is recording.

It keeps a rolling record of each tab in the background, so when something breaks the evidence is already there.

  1. 1

    Pin it and browse normally

    Open the puzzle-piece menu in the toolbar and pin Hindsight. The badge counts failed requests on the current tab.

  2. 2

    When something breaks, scrub back

    Open the side panel to see every request, console error and click in order, with full headers and bodies.

  3. 3

    Share one file

    Save the session as a single HTML replay file that opens in any browser, or send it to Slack, Teams, Discord or a GitHub issue.

Keyboard shortcuts

Change them at chrome://extensions/shortcuts

What stays private

  • Everything is stored on this computer. Hindsight has no server.
  • Authorization, Cookie and API-key headers are masked before anything is written.
  • Password fields and card numbers are never stored.
  • Nothing is sent anywhere unless you press Send or Save.

# Microsoft Edge Eklentileri — Türkçe listeleme

Partner Center → Store listings → **Add a language** → Türkçe.

**Açıklama** (250 – 10.000 karakter):
[`../cws/description-tr.txt`](../cws/description-tr.txt) metnini aynen
yapıştırın.

**Kısa açıklama:**

```
Açmadığınız DevTools. Gizlilik öncelikli, arka planda hata raporu kaydı.
```

**Arama terimleri** (en fazla 7, her biri ≤ 30 karakter):

```
hata raporu
ağ kaydı
konsol hataları
devtools
oturum kaydı
test
har dışa aktarma
```

**Görseller:** `tr/` klasöründeki aynı adlı dosyalar (Türkçe arayüz ve
başlıklarla).
